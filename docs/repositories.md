# Репозитории AgilFrame

Корневой репозиторий фиксирует набор совместимых версий. Core содержит сервер и полный интеграционный workspace. Web SDK, мобильные SDK и ноды можно собирать из отдельных репозиториев. Edge для встраиваемых систем также доступен отдельно. Для публикации Edge нужны запущенный Core и настроенный LiveKit Ingress. [Настройка Edge](https://github.com/GillHD/agilframe-edge)

## Обновление комплекта

Web SDK, Mobile, Nodes и Edge развиваются в своих репозиториях. Контракты протокола и общие части админки развиваются в Core. Интеграционный workspace Core хранит снимки SDK, мобильных компонентов и нод для самостоятельной сборки. Web SDK хранит снимок используемых общих частей Core. Edge запускается из отдельного репозитория даже в сквозном тесте.

1. Опубликуйте изменения в репозитории, который владеет исходниками. Обновите снимки затронутых файлов в зависимых репозиториях.
2. При обновлении Core зафиксируйте тот же SHA в `deploy/.env.example` и в значении по умолчанию в `deploy/compose.yaml`.
3. Обновите Git-подмодули и [манифест версий](../versions.json) в одном коммите. Для существующего клона выполните `git submodule update --init --recursive`.
4. Запустите `node scripts/verify-release.mjs`. Скрипт сверяет манифест, Git-подмодули, Deploy и отслеживаемые файлы общих компонентов. Сквозной CI проверяет вход через виджет, регистрацию Node Agent и передачу медиапотока с Edge через LiveKit. [Workflow](../.github/workflows/verify-components.yml)
