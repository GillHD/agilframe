# Репозитории AgilFrame

Корневой репозиторий фиксирует набор совместимых версий. Core содержит сервер и полный интеграционный workspace. Web SDK, мобильные SDK и ноды можно собирать из отдельных репозиториев. Edge для встраиваемых систем также доступен отдельно. Для публикации Edge нужны запущенный Core и настроенный LiveKit Ingress. [Настройка Edge](https://github.com/GillHD/agilframe-edge)

## Обновление комплекта

1. Опубликуйте проверенные изменения в репозитории компонента.
2. В общем репозитории обновите ссылку на точный коммит компонента и укажите, какая версия Core с ним проверена.
3. Проверьте новое клонирование с `--recurse-submodules`. Для существующего клона используйте `git submodule update --init --recursive` после обновления корневого репозитория.
4. Для обновления нескольких компонентов выполните интеграционную приёмку до изменения ссылок. [План публикации](https://github.com/GillHD/agilframe-core/blob/main/docs/release/repositories.md)
