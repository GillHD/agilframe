# Вклад в AgilFrame

Русский · [English](CONTRIBUTING.en.md)

Вносите изменение в репозиторий компонента. Используйте [общие правила Issues и pull requests](https://github.com/GillHD/agilframe-core/blob/main/CONTRIBUTING.md). Автор PR лично проверяет весь diff и отвечает за изменения, включая код, подготовленный с помощью ИИ.

Для изменения этого репозитория проверяйте ссылки, состав подмодулей и команды клонирования. При обновлении ссылки на компонент укажите его PR, старый и новый SHA и проверку совместимости.

## Ветки и pull requests

- Создавайте ветку от актуальной `main`. Используйте `feature/…` для функций, `fix/…` для исправлений и `docs/…` для документации. В имени коротко укажите задачу, например `docs/english-quick-start`.
- Открывайте один PR на одну связанную задачу. В описании укажите пользовательский сценарий, изменения по компонентам, проверки и результат. Свяжите PR с Issue, если оно есть.
- Перед слиянием обновите ветку, дождитесь зелёной проверки выпуска и интеграции, закройте замечания. `main` защищена, изменения вливаются через PR.

## Коммиты

Пишите короткий заголовок в повелительном наклонении. Укажите конкретное действие, например `Verify the Edge publisher against the pinned Core`. Для существенного изменения добавьте тело. Опишите, что изменилось, зачем и как вы проверили результат. Если требуется миграция или обновление конфигурации, укажите это отдельно.

```text
Document the demo room verification flow

Explain when the organizer receives the check and when Core closes
an unverified room. Link the public demo and the API reference.

Verification: check public links and open the demo on mobile.
```
